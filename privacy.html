SocialTotal Demo policy

Privacy without weirdness.

This repository currently contains a browser demo. This page describes the demo behavior and must be expanded before a public production launch.

Local demo data

Demo profile details, plan selection, connected-state labels, and publishing history are stored in your browser using localStorage. Uploaded media files are not persisted by this demo after the page session.

Google and YouTube

If a Google OAuth client ID is configured, Google Identity Services handles Google sign-in and YouTube authorization. SocialTotal requests YouTube scopes only to identify the connected channel and upload videos the user explicitly chooses. Short-lived access tokens are kept in memory by this frontend demo and are not written to localStorage.

Other platforms

TikTok, Instagram, Facebook, Discord, payments, and durable authentication require a production backend. The default demo simulates these connections locally instead of collecting real passwords or secret tokens.

Advertising

The demo contains advertising placements for Free and Spread plans. A real advertising provider may collect information under its own policies once configured. Total plan UI hides SocialTotal ad placements.

Before production

Add your business identity, contact method, retention periods, deletion workflow, provider-specific disclosures, cookie/consent behavior, and any legally required regional terms before inviting real users.
